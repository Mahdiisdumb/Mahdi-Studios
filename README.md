# Mahdi Studios

**Mahdi Studios – Where Dumb Ideas Become Code (and Sometimes Work)**

## What This Is

Mahdi Studios is not a serious tech brand. It’s a **celebration of chaos, stubbornness, spaghetti code, and sheer will**. We make things, break things, laugh at bugs, and somehow sometimes accidentally ship something that kinda works. Everything here is open source because of bad decisions, not good planning.

The live website literally says we are:
- Powered by stubbornness  
- Fueled by bad ideas  
- Probably created by 12‑13 year olds  
- Proudly chaotic and unpolished 

## What’s in This Repo

This repo contains the source code for the Mahdi Studios website, including:

index.html – main landing page HTML
style.css – styling for the site
script.js – interactive bits
hero.png – header image
favicon.ico – site icon


## Philosophy

If something works, it was probably an accident.  
If it breaks, that’s normal.  
Bugs are features. Glitches are art.  
Stubbornness is our project management strategy.  
We write code because we think we *might* know what we’re doing — and we probably don’t.
